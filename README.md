# UX AI Hacktahon 2026

This repository contains a starter kit for working with the Figma MCP server.

Note: There are hidden directories in this repository.

## Installation

1. Just copy the content of this repository to your local files 
2. Open it in VSCode or any other MCP client.
3. Install the Figma MCP server extension in VSCode or your MCP client.
4. Select the Figma Agent in your MCP client.
5. Prompt away!

## Contents

### Agent Skills

- Figma Create New File \
  This skill enables the LLM to create a new Figma file with a specified name and description.
- Figma Generate Design \
  This skill allows the LLM to generate a design from a URL.
- Figma Implement Design \
  This skill enables the LLM to implement a design from Figma in code.
- Figma Use \
  This skill allows the LLM to create or modify a design in Figma based on a prompt.
